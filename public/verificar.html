Verificar instalação

Esta página verifica se a hospedagem está entregando os arquivos necessários. Não acessa a câmera nem envia informações a terceiros.

Clique para iniciar a verificação. Se o botão não responder, o servidor pode estar bloqueando o arquivo JavaScript.

    Na hospedagem compartilhada, envie o conteúdo completo do pacote andante-site-superdominios-v2.zip para a pasta public_html/andante/, incluindo o arquivo oculto .htaccess. O ZIP de código-fonte baixado do GitHub precisa ser compilado antes de publicar.

    Para solicitar ajuda, copie os resultados desta página e informe o navegador/dispositivo usado.
